Set up your wallet

On StartOS, the wallet is set up with a StartOS action, not on this page.

  2. Open Actions and run the wallet setup action.
  3. Paste the Silent Payments descriptor from Sparrow and the birthday height Sparrow shows for this wallet.
  4. Start the service. This page then shows the wallet address and the scan.

New wallet

The current wallet is kept on this box as a backup until the new one has verified progress, so you can restore it. Sparrow shows the new wallet's payments as the rescan finds them.

Restore previous wallet

If a wallet change went wrong, put the previous wallet back. The backup is deleted once the new wallet has verified progress for 24 hours.

The current wallet is replaced by the one set up before the last change, and friglet continues from that wallet's saved scan.

Forget wallet

Deletes this wallet's configuration, key, scan progress and backup from this box, then returns to setup. Your funds and your Sparrow wallet are not affected.

Diagnostics

A diagnostics download, built only from structured data and never from raw logs, comes in a later version. Until then, the logs on your platform show what friglet is doing.

Where the logs are

friglet's logs currently contain transaction ids, amounts and IP addresses. Share them only with people you trust, and remove those details before posting them anywhere public.

Umbrel
On the Umbrel home screen, open the friglet app's menu and choose Troubleshoot.
StartOS
In StartOS, open Services, then friglet, then Logs.
RaspiBlitz
Over SSH: sudo journalctl -u friglet -n 200
myNode
On the friglet app page in myNode, open the logs. Over SSH: sudo journalctl -u friglet -n 200
Docker Compose
In the folder with the compose file: docker compose logs --tail 200
