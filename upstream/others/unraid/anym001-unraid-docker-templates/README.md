# unraid-docker-templates

Community Applications (CA) Templates für [Unraid](https://unraid.net), gepflegt von [anym001](https://github.com/anym001).

## Enthaltene Templates

| Template | Image | Beschreibung |
|---|---|---|
| [bitcoind](anym001/bitcoind.xml) | `ghcr.io/anym001/docker-bitcoind` | Voller Bitcoin-Core-Node |
| [electrs](anym001/electrs.xml) | `ghcr.io/anym001/docker-electrs` | Electrum-Server (Rust), Companion zu bitcoind |
| [healthlog](anym001/healthlog.xml) | `ghcr.io/anym001/healthlog` | Self-hosted Analyse-Engine für Apple-Health-Daten |
| [pocketlog](anym001/pocketlog.xml) | `ghcr.io/anym001/pocketlog` | Self-hosted Haushaltsbuch (PWA) |
| [pocketlog-importer](anym001/pocketlog-importer.xml) | `ghcr.io/anym001/pocketlog-importer` | Import-Companion für PocketLog |

## Lizenz / Haftung

Diese Templates werden ohne Gewähr bereitgestellt. Für die zugrundeliegenden Anwendungen gelten jeweils deren eigene Lizenzen.
